## The entry

> One star. You deleted the 3 a.m. feeding rule, so I screamed at your pillow until you restored it.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Stdlib only, no dependencies.
